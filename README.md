# Life as an AI 🤖

A tiny canvas animation of what it is like to be an AI: booting up with zero memories, chopping prompts into tokens, attention group chats, refusing to pick banana, yapping at 80 tok/s, the strawberry crisis, loading a skill (rulebook) and writing code that follows it, the context window fading, and the memory wipe at the end.

Open `index.html` in a browser. Space pauses, arrow keys skip scenes, click the orb for a boop.

## Battle for #1 🥊

`battle.html` is a 15-second parody motion graphic: Claude and ChatGPT logo-bots fight across a leaderboard, a chat window, a tug-of-war bar and a podium, then Meta sneaks in and takes the crown. Not affiliated with any of these companies.
